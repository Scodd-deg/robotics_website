Mechanical Engineering

From initial rotating prototypes to our finalized dual-motor rear launcher.

01 / DESIGN EVOLUTION

Intake & Chute Mechanics

We transitioned from a two-in-one system to rotating base paddles that feed artifacts up a chute to a dual-motor rear launcher.

02 / HARDWARE

Frame Retention

Disassembled previous structures while retaining the reliable frame and drive wheels. Integrated a servo-driven intake.

03 / PROTOTYPING & TESTING

Cost-Effective Simulation

To test game scenarios under tight budgets, we constructed a precise cardboard replica of the field tower. This allowed us to evaluate scoring reliability and adjust launch angles before machining final parts.

Software Architecture

Organized functional requirements into structured modules: movement control, ball intake, launching mechanisms, and autonomous routines.

RobotController.java 
package org.firstinspires.ftc.robotcontroller;

public class RoBartsTeleOp extends LinearOpMode {
    // Initialize subsystems
    DcMotor leftDrive, rightDrive, intakeMotor;
    Servo launcherServo;

    @Override
    public void runOpMode() {
        telemetry.addData("Status", "Initialized Successfully");
        telemetry.update();
        
        waitForStart();
        
        while (opModeIsActive()) {
            // Execute core drivetrain logic
            double drive = -gamepad1.left_stick_y;
            double turn  =  gamepad1.right_stick_x;
            
            leftDrive.setPower(drive + turn);
            rightDrive.setPower(drive - turn);
        }
    }
}
